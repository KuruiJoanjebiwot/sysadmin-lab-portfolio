# Sysadmin Lab Portfolio

This repository contains an infrastructure lab portfolio covering:
* **Active Directory:** Domain controller management and automated RSAT tools.
* **Ansible:** Base system configuration and package deployment playbooks.
* **Docker:** Containerized service stacks and host monitoring agents.
* **Zabbix:** Multi-container Zabbix 6.4 LTS server, MySQL backend, and web frontend.

---

## Directory Structure
* `active-directory/` - AD lab configurations and documentation.
* `ansible/` - Inventory files (`hosts`) and playbook tasks (`site.yml`).
* `docker/` - General service container stacks.
* `zabbix/` - Centralized monitoring stack definition.
* `docs/` - Architecture notes and verification screenshots.
